# 首都圏外郭放水路(埼玉県春日部市)を光で見る 3D操作ページ

台風6号(2026/6/3〜6/4)で稼働した首都圏外郭放水路を、実寸(1:1)・公表値で光らせます。**公表値による再現**です。

- 立坑5本・トンネル(約6.3km)・調圧水槽(長さ177m×幅78m×高さ18m、柱59本)・排水機場・排水樋管を選ぶと、右側の詳細パネルに公式資料の数値と出典が出ます。
- 【公表】【公表(グラフ読み取り)】【推定】【演出】【記載なし】のタグで区別しています。
- 経路・柱の配置・調圧水槽の位置は推定/模式です。水の動きと音は演出です。速報値は今後修正される可能性があります。

出典: 国土交通省関東地方整備局 江戸川河川事務所(パンフレット・施設概要・台風6号出水速報)、地図: 国土地理院、座標: © OpenStreetMap contributors(ODbL)。詳細は `SOURCES.md`。
