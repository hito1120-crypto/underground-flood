# 台風6号(2026/6/3)で稼働した地下の治水施設を光で見る

東京の神田川・環状七号線地下調節池(A)と、埼玉の首都圏外郭放水路(B)を、同じ時間軸・同じ縮尺(1:1)で並べて光らせる3D操作ページです。**公表値による再現**です。

- 実測値(公表値)・グラフ読み取り値・補間/推定・データなし を色で区別しています。
- 台風6号の公表値は速報値を含み、今後修正される可能性があります。
- 経路は道路中心線・立坑のOSM座標に基づく推定です。AとBは実際には約32km離れており、画面では並べて配置しています。
